# 代码 名称 板块 最新价 涨跌幅 历史最低qfq 首发价 分母 倍数 ▲ 底部距离
口径说明：分母 = Min(上市以来前复权最低价, 首发价格)，每个交易日盘后由 GitHub Actions 重建（除权除息会改变前复权序列，故需每日重算）； 老股票缺首发价时分母仅取历史最低。最新价来自东方财富公开行情接口，由浏览器直连拉取，约数秒延迟。 停牌（最新价为 "-"）与缺分母的股票不参与排序。
